# convex sets & functions · lab notes

## experiment 1: which ML losses are convex?

**what people usually predict:** the "classical" losses (squared, absolute, logistic, hinge, softmax) are convex and the neural network isn't. many people also expect squared error on a sigmoid to be convex ("squared error is convex, the sigmoid is monotone"), and most expect the deep linear model $abx$ to be convex because the model is linear in its input.

**what happens:** your checker finds violations for exactly four losses: squared error on a sigmoid (most negative gap about **−0.13**, Hessian eigenvalue down to **−0.07**), the deep linear model (gap **−19**, eigenvalue **−34**), the tanh unit (gap **−5.1**) and matrix factorization (gap **−103**). the five classical losses show no violation. for absolute error and hinge, the most negative gap is around $-10^{-15}$ (rounding, inside the relative tolerance) and the "Hessian eigenvalues" are around $-10^{-7}$: noise. softmax cross-entropy also has a smallest Hessian eigenvalue of essentially 0 (about $-10^{-7}$).

**why:** the five convex losses are each a convex function of $w^\top x$ (or $W^\top x$), averaged over the data: affine precomposition plus a nonnegative sum. the sigmoid breaks the affine rule: $(\sigma(z) - y)^2$ is a convex function of $\sigma$, but $\sigma$ is not affine in $z$, and the composition rule needs the outer function to be nondecreasing *and* the inner one convex; $\sigma$ is neither convex nor concave. for $y = 1$, the loss $(1 - \sigma(z))^2$ flattens out as $z \to -\infty$ (a plateau), and a function that's flat on one side and curves up on the other must bend the wrong way somewhere. cross-entropy fixes this: $-\log\sigma(z) = \log(1 + e^{-z})$ is convex in $z$, because the log undoes the exponential in the sigmoid. (that's one of the reasons logistic regression uses cross-entropy, not squared error.)

the deep linear model and matrix factorization fail for a different reason: **symmetry**. $(a, b)$ and $(-a, -b)$ give the same product, so the same loss; their midpoint $(0, 0)$ gives the model $0$, which is worse. any loss with two separated global minima related by a symmetry, and a worse point in between, is nonconvex. a neural network has such symmetries everywhere (flip the signs of a tanh unit's weights in and out; permute hidden units), which is one reason its loss is nonconvex even when each layer is linear.

the Hessian test is meaningless for absolute error and hinge: their Hessian is 0 almost everywhere and undefined on the kinks, so `numerical_hessian` returns finite-difference noise (and, if a sample point sits near a kink, a huge positive number). softmax cross-entropy has an exactly flat direction: adding the same vector to every column of $W$ adds the same number to every logit, which doesn't change the softmax. so it's convex but not *strictly* convex, and its minimizer isn't unique without a penalty (on paper 3 has the same flat direction for log-sum-exp).

## experiment 2: a needle in a haystack

**what people usually predict:** the Hessian test fires sooner, because it only needs one point in the bad region while Jensen needs a whole pair. at $n = 50$, people guess something like "Hessian 50%, Jensen 10%".

**what happens:** it's the other way round. with the default width ($s = 0.02$), the Hessian test catches the bump in **38%** of 50 runs at $n = 50$ and **76%** at $n = 200$; the Jensen test catches it in **68%** at $n = 50$ and **100%** at $n = 200$. both miss it most of the time at $n \le 25$ (12–32%). widen the bump with the slider and both rates go up; narrow it and both go down.

**why:** the concave region (where $f'' < 0$) is about $2s = 0.04$ wide, so a single uniform point on $[-2, 2]$ lands in it with probability about $0.01$, and the Hessian test with $n$ points fires with probability about $1 - 0.99^n$: 40% at $n = 50$, 63% at 100, 87% at 200 (measured over 50 runs: 38%, 60%, 76%). the Jensen test doesn't need a point in the concave region at all. it needs a chord whose interior point lands on the *bump* (a region several $s$ wide) while its ends are close enough that the parabola's own sag, $t(1 - t)\Delta^2$ for a chord of length $\Delta$, is smaller than the bump's height $h = 0.01$: that's $\Delta \lesssim 0.25$. with $n^2/2$ pairs and three values of $t$, there are thousands of chances. Jensen tests the function at a *scale* (the chord length), the Hessian test only at a point, and a bump is easier to see from a little distance than from inside its inflection zone.

the bigger lesson is the left end of the plot: with 10–25 points, both tests usually report "no violation found" for a function that isn't convex. a numerical convexity check is a search for a counterexample, and its silence means only that the search failed. if you need convexity, prove it (with the composition rules or a Hessian you can bound by hand); use the checker to catch mistakes in the proof.

## experiment 3: convex sublevel sets, nonconvex function

**what people usually predict:** for the Welsch loss, "its contours are circles, so it's convex", or "it's bounded, so it can't be convex" with no view on the sublevel sets. for the $\ell_{1/2}$ penalty, most people have no prediction.

**what happens:** for the Welsch loss, your `set_convexity_violation` finds no violation in its sublevel set $\{f \le 0.8\}$ (it's a disk), but `check_convexity` finds that the function itself is **not convex**. for the $\ell_{1/2}$ penalty both fail: its sublevel set $\{g \le 1.5\}$ is a four-pointed star (the contour plot shows it), and the function isn't convex.

**why:** sublevel sets only record *which* points are below each level, not *how fast* the function rises. along any ray from the origin, the Welsch loss is $1 - e^{-r^2}$, an S-shaped curve: convex for $r < 1/\sqrt2 \approx 0.707$ and concave beyond (it flattens towards 1), but always increasing, so every sublevel set is a disk. a function with all sublevel sets convex is called **quasiconvex**; Jensen's inequality is replaced by $f(tx + (1 - t)y) \le \max(f(x), f(y))$. the implication goes one way only: if $f$ is convex and $f(x), f(y) \le c$, Jensen gives $f(tx + (1 - t)y) \le c$, so convex functions have convex sublevel sets; the Welsch loss shows the converse fails. robust losses like Welsch and Cauchy are quasiconvex on purpose: their flat tails stop outliers from dominating, and the price is nonconvexity (multiple local minima in robust regression).

the $\ell_{1/2}$ penalty isn't even quasiconvex. its sublevel sets are stars with spikes along the axes, and that shape is why it promotes sparsity more aggressively than $\ell_1$ (whose sublevel sets are diamonds, the convex hull of those stars): the point of a sublevel set where a loss contour first touches it is very likely to be a spike tip, i.e. a point with some coordinates exactly zero. $\ell_1$ is the *convex relaxation* of such penalties: on the box $[-1, 1]^n$ it's the tightest convex function below the $\ell_{1/2}$ penalty (its convex envelope). ch 08's lasso uses it, and accepts a bit less sparsity in exchange for a convex problem.
