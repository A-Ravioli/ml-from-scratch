# temporal-difference learning · lab notes

## experiment 1: cliff walking

**what people usually predict:** Q-learning, which learns the optimal policy, earns the most reward; SARSA is "the worse algorithm".

**what happens:** averaged over the last 100 of 500 episodes and 10 runs, the ε-greedy returns are SARSA **−27.7**, Q-learning **−46.9**, expected SARSA **−20.5**. Q-learning's greedy path is the optimal 13-step path along the cliff edge; SARSA's (21 steps in run 0) and expected SARSA's (15 steps) keep a row or more away from the edge. Q-learning's learning curve stays noisy and low throughout: it keeps falling off.

**why:** each method's $Q$ is the value of a different policy. Q-learning's target uses $\max_aQ(s', a)$, so it learns $Q^*$, the values of the greedy policy, for which the edge is safe. but the agent *behaves* ε-greedily, and on each of the 10 edge cells a random "down" (probability $0.1/4 = 0.025$) costs $-100$ and a restart: about one fall every four episodes, which is the gap between the curves (on paper 2). SARSA's target uses the action the ε-greedy policy actually takes, so it learns the values *including* the exploration, discovers that the edge is dangerous for an exploring agent, and routes around it. expected SARSA learns the same ε-greedy values with less noise in its target (it averages over the next action instead of sampling it), so with $\alpha = 0.5$ it learns faster and more smoothly than SARSA; its path is the shortest safe one. if $\varepsilon$ decayed to 0, SARSA's policy would converge to the greedy-optimal one too, and both curves would approach $-13$. the general lesson: "optimal" is relative to the policy you'll run. on-policy methods optimize the behaviour you actually have; off-policy methods optimize a behaviour you'll switch to later.

## experiment 2: how much λ?

**what people usually predict:** either TD(0) or Monte Carlo wins, or a smooth trade-off with no clear optimum; few expect anything to diverge.

**what happens:** at their best step sizes, the RMS errors after 10 episodes are: $\lambda = 0$: **0.222** (at $\alpha = 0.8$), $\lambda = 0.4$: **0.168** ($\alpha = 0.6$), $\lambda = 0.8$: **0.183** ($\alpha = 0.2$), $\lambda = 0.9$: **0.235** ($\alpha = 0.1$), $\lambda = 0.95$: **0.263**, $\lambda = 1$: **0.518** (at the smallest $\alpha$ tried). every curve is U-shaped in $\alpha$, the minimum moves to smaller $\alpha$ as $\lambda$ grows, and for $\lambda \ge 0.9$ the errors explode for large $\alpha$: at $\alpha = 1$ they diverge to infinity.

**why:** intermediate $\lambda$ trades bias against variance. TD(0) propagates information one state per visit, so after 10 episodes the values far from the ends are still near 0 (bias); Monte Carlo uses the full return, an unbiased but noisy $\pm1$ for every state of the episode, and averaging 10 of them is noisy (variance). a moderate $\lambda$ spreads each TD error a few states back, which propagates information quickly without inheriting the full return's noise. the U-shape in $\alpha$ is the usual step-size trade-off: too small learns slowly, too large chases noise. the blow-up is a property of **accumulating** traces: a random walk revisits states over and over within an episode, so their traces pile up well above 1 (towards $1/(1 - \lambda)$ for a state visited every step), and the effective step $\alpha e(s)$ exceeds 1: each update overshoots, the next TD error is larger, and the values diverge. replacing traces or true online TD($\lambda$) don't have this problem. Sutton & Barto's Figure 12.3 shows the same picture for the offline λ-return; Figure 12.6 shows the accumulating-trace instability.

## experiment 3: a time limit is not a cliff

**what people usually predict:** that both versions learn something close to the exact values, maybe with the buggy one slightly off; or that neither can learn values for episodes longer than 15 steps.

**what happens:** the exact $V(\text{start})$ of the time-unlimited gridworld is **−18.32**. TD(0) that bootstraps on truncation learns **−17.89** (mean absolute error 0.93 over the grid, which is constant-step-size noise). the version that treats time-outs as terminal learns **−9.65** (mean absolute error 9.47): every value is about half what it should be, and the error is largest far from the goal.

**why:** bootstrapping makes TD's target $r + \gamma V(s')$ a statement about the time-unlimited problem: the value of $s'$ includes its whole future, whether or not this episode got to see it. cutting episodes off at 15 steps only changes which transitions you sample, not what each update means, so TD still converges to the exact $V^\pi$. the buggy version learns the value of a *different* MDP, one in which a trap door opens after 15 steps and ends everything at no cost. a cost-per-step agent loves that trap door: states far from the goal, whose episodes usually hit the time limit, look much better than they are. a learner that used these values for control would happily dawdle until the clock runs out. Pardo et al. (2018) show the same effect in deep RL benchmarks; it's why Gymnasium split `done` into `terminated` and `truncated`, and why ch 24's DQN target and GAE use only `terminated` to cut the bootstrap.
